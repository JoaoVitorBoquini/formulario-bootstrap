# Formulário HTML com Bootstrap

## Mostra de Tecnologia e Inovação

## Objetivo do projeto

Desenvolver um formulário de inscrição para a Mostra de Tecnologia e Inovação, utilizando HTML5, CSS3 e Bootstrap, com diferentes tipos de campos, validações nativas e layout responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git e GitHub

## Tipos de input utilizados

- `text`: entrada de textos.
- `email`: entrada de e-mail com validação de formato.
- `password`: entrada de senha.
- `number`: entrada de números.
- `tel`: entrada de telefone.
- `url`: entrada de endereço de site.
- `search`: campo para pesquisa.
- `date`: seleção de data.
- `month`: seleção de mês e ano.
- `week`: seleção de semana.
- `time`: seleção de horário.
- `datetime-local`: seleção de data e horário.
- `color`: seleção de cor.
- `range`: seleção de um valor em um intervalo.
- `file`: seleção de arquivos.
- `checkbox`: seleção de múltiplas opções.
- `radio`: seleção de uma opção entre alternativas.
- `hidden`: armazenamento de uma informação que não aparece na tela.
- `submit`: envio do formulário.
- `reset`: limpeza dos campos.
- `button`: botão sem ação padrão.
- `image`: botão de envio representado por uma imagem.

## Respostas da investigação

Durante o desenvolvimento do formulário, foram observados alguns pontos importantes:

- O Bootstrap facilita a criação de formulários responsivos, principalmente com as classes de grid.
- Os tipos de input do HTML5 são úteis para cada situação, como `email` para e-mails, `number` para números e `date` para datas.
- A validação nativa do HTML permite definir campos obrigatórios, limites e formatos sem precisar utilizar JavaScript.
- O `fieldset` e o `legend` ajudam a organizar o formulário em diferentes seções.
- As classes do Bootstrap, como `form-control`, `form-select`, `form-check` e `btn`, facilitam a estilização dos elementos.
- Foi possível perceber que o formulário se adapta melhor a diferentes tamanhos de tela utilizando o sistema de grid do Bootstrap.
